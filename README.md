# מוקד 100 סימולטור

משחק דפדפן: משמרת אחת במוקד חירום. עונים לקריאות, שואלים את המתקשר, משגרים ניידות ומזעיקים מד״א, כיבוי ועירייה.

**לשחק:** https://chabotierd.github.io/100simulator/

משחק עצמאי שאינו מוצר רשמי של משטרת ישראל. כל האירועים והדמויות בדויים, ומספרי הבתים אינם קיימים בכוונה. במצב חירום אמיתי מתקשרים 100.

## מבנה

- `index.html` - כל המשחק: עיצוב, נתונים וקוד בקובץ אחד.
- `cine/` - תמונות קטעי המעבר, ארבע לכל אירוע. גרסאות לפי עיר ומשמרת נקראות `עיר-משמרת-מספר`.
- `voice/` - הקלטות קשר ורעש רקע של המוקד.
- `sfx/` - סאונד לקטעי המעבר.
- `op-*.jpg`, `op-*.mp4` - המוקדן והמוקדנית.
- `sw.js` - שומר עותק של המשחק במכשיר, כדי שיעבוד גם בלי אינטרנט. נוצר אוטומטית.

## עדכון המשחק

אחרי כל שינוי בקבצים מריצים `python3 tools/make-sw.py`, כדי שמכשירים שכבר התקינו את המשחק יקבלו את הגרסה החדשה, ודוחפים לשני הענפים: `main` ו-`gh-pages` (האתר מתפרסם מ-`gh-pages`).
